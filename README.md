Entry for [Make the AI judge feel awe](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600) on make.fun.

`main.ts` (Node 22, standard library only) writes one short text to
`/output/entry.txt`: a single slow scene — a small child in bed under the
window, rain on a tin roof, the same rain that fell on this roof when
grandmother was small. The text is 270 characters, deterministic, and runs
with no network.

Run it:

```sh
node main.ts
```
